One sentence, up to 200 characters, that makes a small everyday moment strange and new: a shadow arriving a step late on wet pavement.

## Run it

```sh
MAKEFUN_OUT_DIR=./out node main.ts
```

The program writes one sentence to `./out/entry.txt` (or `$MAKEFUN_OUT_DIR/entry.txt`).
